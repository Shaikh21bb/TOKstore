# ТОК — MVP магазина мобильных аксессуаров

Рабочее название и демонстрационные товары. Интерфейс на русском, цены в рублях.

## Выполненный план

1. Создать адаптивную витрину с понятной навигацией.
2. Добавить 12 демонстрационных товаров, категории, поиск, подбор по устройству и сортировку.
3. Реализовать карточки товаров, избранное, корзину, изменение количества и удаление.
4. Добавить демонстрационное оформление: имя, телефон, самовывоз или курьер, расчёт суммы.
5. Сохранять корзину, избранное и до 20 демо-заказов в localStorage; скачивать текстовое подтверждение.
6. Проверить основные сценарии на настольном и мобильном экране и опубликовать MVP.

## Запуск

Зависимости и сборка не нужны. Из этой папки:

```sh
python -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. Для хостинга использовать содержимое `dist`.

## Что подключить для реальных продаж

- Название магазина, юридические реквизиты, реальные товары, цены, остатки и контакты.
- Серверное хранение и обработку заказов, панель администратора.
- Платёжного провайдера, доставку и уведомления.
- Публичный доступ, домен, политику обработки данных и условия продажи.

Заказы не отправляются продавцу, оплата не производится. Имя, телефон и адрес используются только для проверки формы и не сохраняются в истории заказов. Демонстрационные тарифы: самовывоз — 0 ₽, курьер — 350 ₽. Образцы SVG-иллюстраций создаются `python make-assets.py`. Шрифт Manrope загружается с Google Fonts; при недоступности используется системный Arial.
